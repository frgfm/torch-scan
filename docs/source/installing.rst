
************
Installation
************

This library requires `Python <https://www.python.org/downloads/>`_ 3.11 or higher.

Via Python Package
==================

Install the last stable release of the package using `pip <https://pip.pypa.io/en/stable/installation/>`_:

.. code:: bash

    pip install torchscan


Via Git
=======

Install the library in developer mode using `uv <https://docs.astral.sh/uv/>`_:

.. code:: bash

    git clone https://github.com/frgfm/torch-scan.git
    cd torch-scan
    uv venv
    uv pip install -e .
